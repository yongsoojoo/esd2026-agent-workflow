기초 C · Raspberry Pi 초기 설정

SD 카드에 OS 를 쓰고, 노트북에서 SSH 로 접속하기

처음 받은 Raspberry Pi 3 B+ / 4 를 노트북에 유선으로 연결해 SSH 로 다루는 데까지 갑니다. 이 페이지는 수업 자료 「Raspberry Pi 설정」 의 절차를 옮겨 정리한 것입니다. 수업 자료의 화면은 macOS 기준이며, Windows 절차는 함께 적되 수업 전에 자기 노트북에서 한 번 확인합니다.

§0설정 목표

  1. 노트북은 Wi-Fi 로, Raspberry Pi 는 노트북의 연결 공유로 외부 인터넷에 연결됩니다.
  2. 노트북에서 Raspberry Pi 를 유선 LAN 의 SSH 로 원격 접속할 수 있습니다.
  3. Raspberry Pi 에 WiringPi 를 설치해 gpio readall 이 실행됩니다.

준비물: Raspberry Pi 3 B+ 또는 4 · 정격 전원 어댑터 · microSD 카드 (16 GB 또는 32 GB) 와 USB 카드 리더 · LAN 케이블 · (노트북에 LAN 단자가 없으면) USB LAN 어댑터.

§1OS 설치 — Raspberry Pi Imager

  1. Raspberry Pi Imager 를 노트북에 설치합니다.
  2. OS 이미지를 정합니다. 수업 기본은 Raspberry Pi OS (32-bit) 입니다 (운영체제 목록). 직접 내려받은 이미지는 Imager 의 OS 선택 창 맨 아래 「사용자 정의 사용」 으로 고릅니다.
  3. Imager 를 실행해 장치를 고릅니다 (Raspberry Pi 3 또는 4).
  4. microSD 카드를 USB 리더로 연결하고 저장소를 고릅니다.

주의저장소 선택에서 실수로 노트북의 내장 디스크를 고르면 노트북의 운영체제가 지워집니다. 고른 장치의 용량이 SD 카드 용량 (16 GB · 32 GB) 과 같은지 확인합니다. 확신이 들지 않으면 쓰기 전에 손을 들고 도움을 요청합니다.

  1. 「OS 커스터마이징 설정을 적용하시겠습니까?」 에서 설정을 편집하기를 누릅니다.
    • 일반 탭: 사용자 이름과 비밀번호를 정합니다. 무선 LAN 은 설정하지 않습니다 (강의실에서는 유선을 씁니다).
    • 서비스 탭: SSH 사용과 비밀번호 인증 사용을 체크하고 저장합니다.
  2. 커스터마이징 적용에 「예」, 쓰기 확인 창에서 장치 이름을 한 번 더 확인하고 「예」 를 누릅니다.
  3. 쓰기가 끝나면 SD 카드를 빼서, 전원이 꺼진 Pi 뒷면의 슬롯에 넣습니다. 아직 전원을 넣지 않고 §2 의 고정 주소 설정을 먼저 합니다.

32 / 64-bit노트북에서 에이전트를 쓰고 Pi 에서는 SSH 로 실행만 하는 기본 구성 (5. 실습 환경 §1) 에서는 32-bit 로 충분합니다. Pi 4 에서 Kiro CLI 같은 에이전트를 직접 돌리려면 64-bit OS 가 필요합니다.

§2유선 연결과 고정 주소

노트북과 Pi 를 LAN 케이블로 바로 잇고, 두 기기에 정해진 주소를 줍니다. 수업 자료의 주소는 노트북 192.168.2.1 · Pi 192.168.2.2 입니다.

Pi 쪽 — cmdline.txt

SD 카드를 노트북에 꽂으면 bootfs 라는 드라이브가 보입니다. 그 안의 cmdline.txt 를 열어 한 줄로 된 내용의 맨 끝에 공백 하나와 아래 내용을 덧붙입니다.

ip=192.168.2.2::192.168.2.1:255.255.255.0:rpi:eth0:off

주의cmdline.txt 는 반드시 한 줄이어야 합니다. 줄바꿈을 넣으면 Pi 가 부팅하지 못할 수 있습니다. macOS 는 터미널에서 cd /Volumes/bootfs 후 nano cmdline.txt, Windows 는 메모장으로 엽니다.

저장한 뒤 SD 카드를 안전하게 꺼내 Pi 에 넣고, LAN 케이블로 노트북과 연결한 다음 전원을 넣습니다. 첫 부팅은 초기화 작업 때문에 2 분 이상 기다립니다.

노트북 쪽 — 유선 어댑터 주소

환경설정 위치값
macOS시스템 설정 → 네트워크 → (USB LAN 등 유선 어댑터) → 세부사항 → TCP/IPIPv4 구성 수동 · IP 주소 192.168.2.1 · 서브넷 마스크 255.255.255.0 · 라우터 192.168.2.1
Windows설정 → 네트워크 및 인터넷 → 이더넷 → IP 할당 편집 → 수동 → IPv4IP 주소 192.168.2.1 · 서브넷 마스크 255.255.255.0 (접두사 길이 24)
 
ping 192.168.2.2          # 응답이 오면 유선 연결 성공 (Windows 는 4 번 보내고 끝납니다)

§3SSH 접속

ssh <사용자 이름>@192.168.2.2
# 처음 접속하면 지문 (fingerprint) 확인을 묻습니다 → yes
# §1 에서 정한 비밀번호 입력 → 프롬프트가 <사용자 이름>@<호스트>:~ $ 로 바뀌면 성공

Windows 10 / 11 은 SSH 클라이언트가 기본으로 들어 있어 PowerShell 에서 같은 명령을 씁니다. 접속을 끝낼 때는 exit 를 입력합니다.

§4인터넷 연결 공유 — Pi 가 노트북을 통해 인터넷에 나가기

노트북은 Wi-Fi 로 인터넷에 연결하고, 그 연결을 유선으로 Pi 에 나눠 줍니다.

  • 노트북 Wi-Fi: 강의실 전용 Wi-Fi 에 연결합니다 (이름과 비밀번호는 수업에서 안내합니다). 학교 공용 Wi-Fi (KMU, KMU(5G)) 는 연결 공유를 지원하지 않습니다.
  • Pi 의 Wi-Fi 를 직접 쓰는 것은 강의실에서 권하지 않습니다.

macOS

  1. 시스템 설정 → 일반 → 공유 → 인터넷 공유: 「연결 공유」 를 Wi-Fi, 「다음 사용」 에서 Pi 에 연결한 유선 어댑터를 체크하고 켭니다.
  2. 켜기 전에 서비스 순서를 확인합니다: 시스템 설정 → 네트워크 → 오른쪽 아래 「…」 → 서비스 순서 설정 → 외부 인터넷에 연결된 Wi-Fi 를 가장 위로 옮깁니다. 유선 어댑터가 위에 있으면 노트북의 외부 인터넷이 막힙니다.

Windows (참고 — 수업 전에 자기 노트북에서 확인합니다)

  1. 제어판 → 네트워크 및 공유 센터 → 어댑터 설정 변경 → Wi-Fi 어댑터 속성 → 공유 탭 → 「다른 네트워크 사용자가 이 컴퓨터의 인터넷 연결을 통해 연결할 수 있도록 허용」 을 체크하고, 홈 네트워크 연결에서 Pi 에 연결한 이더넷을 고릅니다.
  2. Windows 는 이때 이더넷 주소를 192.168.137.1 로 바꿉니다. 그러므로 Pi 의 cmdline.txt 를 아래처럼 맞추고, SSH 주소도 192.168.137.2 로 씁니다.
ip=192.168.137.2::192.168.137.1:255.255.255.0:rpi:eth0:off

확인 (Pi 에서)

ping -c 3 8.8.8.8         # 인터넷 경로 확인
ping -c 3 github.com      # 이름 해석 (DNS) 확인

첫 줄은 되는데 둘째 줄이 안 되면 이름 해석 문제입니다. 화면을 그대로 조교에게 보여 줍니다.

§5SSH 수동 설정 (§1 의 커스터마이징을 건너뛴 경우)

Imager 에서 사용자 · SSH 설정을 하지 않았다면 SD 카드의 bootfs 에 직접 파일을 만듭니다.

cd /Volumes/bootfs                       # SD 카드의 bootfs (macOS)
touch ssh                                # 빈 ssh 파일: SSH 켜기

echo '<비밀번호>' | openssl passwd -6 -stdin   # 비밀번호 해시 생성 (Linux 의 openssl 에서)
nano userconf                            # 한 줄: <사용자 이름>:<위에서 나온 해시>

Windows 에서는 메모장으로 내용 없는 파일을 만들어 확장자 없이 ssh 라는 이름으로 bootfs 에 저장합니다. userconf 의 해시는 Pi 나 Linux 환경에서 만듭니다. 고정 주소 (§2 의 cmdline.txt) 도 함께 설정합니다.

§6첫 점검과 GPIO 확인 — WiringPi

아래는 학생이 직접 실행하는 시스템 설정입니다 (AGENTS.md §3-4 — 에이전트에게 맡기지 않습니다).

sudo apt-get update
sudo apt-get upgrade        # 30 분 이상 걸릴 수 있습니다. 수업 시간에는 건너뛰고 집에서 합니다

git clone https://github.com/WiringPi/WiringPi
cd WiringPi/
./build
gpio -v                     # 버전과 Raspberry Pi Details (보드 종류 · 메모리) 가 나오면 성공
gpio readall                # GPIO 핀 표가 나오면 GPIO 접근 확인 완료

gpio readall 의 핀 표는 결과를 이미 아는 확인입니다 — 표가 나오면 보드 · 라이브러리 · 권한이 함께 맞았다는 뜻입니다. 이어서 5. 실습 환경 §1 의 점검 (사용자 그룹 · 시각 동기화 · 전원 상태) 을 합니다.

§7Pi 에서 git 준비

  1. git config 로 이름과 noreply 이메일을 설정합니다 (기초 A §3).
  2. Pi 에서 SSH 키를 만들어 GitHub 에 등록합니다 (같은 절).
  3. 자기 저장소를 clone 합니다: git clone git@github.com:<아이디>/<저장소>.git
